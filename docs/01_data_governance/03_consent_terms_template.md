# Fase 1 — Modelo de Termo de Consentimento

> Este texto é modelo operacional. Revisar juridicamente antes de uso.

## Termo de Consentimento para Gravação e Análise de Vídeo Facial em Ambiente de Aprendizagem

Você está sendo convidado(a) a participar de uma atividade de pesquisa/avaliação educacional que utiliza gravação facial durante uma aula multimídia.

## Finalidade

A gravação será usada para analisar microações faciais, como movimentos dos olhos, boca e rosto, com objetivo de estudar interações entre materiais educacionais multimídia e indicadores comportamentais exploratórios.

## Dados coletados

- vídeo facial durante a aula;
- metadados técnicos do vídeo;
- pontos faciais extraídos automaticamente;
- anotações de microações;
- resultados de pré-teste e pós-teste, se aplicável.

## O que não será feito

- O sistema não será usado para diagnóstico médico ou psicológico.
- O sistema não será usado para reconhecimento de identidade.
- O sistema não tomará decisões automatizadas sobre nota, aprovação ou desempenho individual.

## Armazenamento

Os dados serão armazenados em ambiente seguro, com acesso restrito a pessoas autorizadas. O tempo de retenção será informado no estudo.

## Compartilhamento

Dados brutos não serão compartilhados publicamente. Resultados poderão ser divulgados apenas de forma agregada ou anonimizada, quando aplicável.

## Revogação

Você pode revogar seu consentimento e solicitar exclusão dos dados conforme o canal informado pelo responsável pelo estudo.

## Consentimentos específicos

- [ ] Autorizo gravação do vídeo facial.
- [ ] Autorizo extração e armazenamento de pontos faciais/landmarks.
- [ ] Autorizo uso dos dados para treinamento e validação de modelos.
- [ ] Autorizo uso de métricas agregadas em publicações e relatórios.
